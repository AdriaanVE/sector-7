# Generated originals

Generated Anthropic file actions now preserve exact original bytes before Download, Copy, Preview or remote Delete. A typed reference on the fragment wrapper gives the original a durable owner. The reference survives branch duplication, disk hydration and ZIP backup/restore. Cache identity includes provider, deployment, container and file; file requests validate the originating deployment. Legacy unscoped originals stay readable locally without assigning them to today's gateway.

Preview is display-only and retains the hosted part, so it does not change the native-history projection or add duplicate file text to provider replay. Remote Delete keeps the local chip and copy. Remove explicitly drops the message reference. Failed disk saves prevent subsequent actions. Metadata updates patch the current fragment and preserve concurrent wrapper edits. Pending replies cannot save generated files until streaming finishes. Automatic streaming file conversion/deletion and its unsafe settings are disabled.

The obsolete OpenRouter credential callback is removed. The active implementation plan's main sections now reflect the current Sector 7 repository and the user's settled decisions; historical checkpoints remain intact.

## Verification

Eight focused original-file regressions cover exact image bytes, display/native projection, branch ownership, reload, real filesystem ZIP restore, provider/deployment/container collisions, failed-save retry, unowned-save rejection, legacy expiry current-fragment concurrency, exact ownership after shared dedupe, and unrelated opaque metadata. File actions wait for the reply to finish so subsequent stream writes cannot overwrite ownership. Final full suite: 156 pass, 22 skipped for missing vendor credentials. Root and tooling TypeScript, full source lint excluding other worktrees, and the production build pass. The first independent review required fixes for streaming ownership, exact dedupe ownership and opaque metadata scanning. Those changes now have focused regressions; the final focused Claude review approved all three fixes. Review logs are retained locally.

## Limits

The gateway still does not support hosted code execution. These changes protect historical generated artifacts and the existing file UI; they do not claim a successful live hosted-code artifact run. Direct browser artifact action acceptance remains unverified. OpenAI adapter behavior is deferred; the local cache identity prevents future provider collisions. Full roadmap acceptance remains open, including both-model live question continuation and broader browser navigation/read-state checks.
