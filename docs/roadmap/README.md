# Roadmap

Plans are tracked in this repository.

- `future/`: possible work without an implementation commitment.
- `planned/`: reviewed plans awaiting approval or implementation. Each item states approval status.
- `../change_details/`: completed outcomes, replacing the corresponding plan.

Plan sections: Goal, Scope, Decisions, Approach, Verification and Human calls when needed.
A plan records observable behavior, decisions and required checks. Implementation may simplify
its technical approach while preserving those decisions. Scope changes require a human decision.
